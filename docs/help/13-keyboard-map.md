# Keyboard map
- F1 help
- F5 next scene
- F6 pause automation
- F7 resume
- F8 emergency blackout (visual and lighting, latched)
- Shift+F8 restore
- Ctrl+S save (Ctrl+Shift+S save as)
- 1 to 8 scene pads (not while you are typing in a text field)
- Ctrl+Tab and Ctrl+Shift+Tab next and previous tab
- Tab and Shift+Tab move between controls; the focused control has a visible frame
Shortcuts work inside the StageSignal window only; they are not global hotkeys. Auto-repeat is ignored.
