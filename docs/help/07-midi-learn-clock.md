# MIDI learn and clock
1. Setup tab: choose the MIDI input and output ports.
2. MIDI / Lighting tab: choose an action, press Learn, then move the control. Press Commit learned.
3. Relative encoders: choose the encoder mode and tick the confirmation box. Absolute CC mappings need no confirmation but relative ones stay inactive until you confirm the mode.
A lost device marks its mappings unavailable; reconnecting does not replay old actions.
MIDI clock output and MIDI feedback are opt-in. Feedback loops are detected and the route is suspended with an alarm.
