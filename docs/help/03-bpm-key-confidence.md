# BPM and key confidence
- Estimated: detected from the audio. The percentage is the confidence. Silence or unclear audio shows Unknown, never a made-up value.
- Tap: tap tempo overrides the estimate until you press Release.
- Manual: a typed BPM or key also overrides until released.
- Beat-length cues wait for a valid tempo; free-time cues use elapsed time and never assume a BPM.
- Each audience output has its own overlay switches for text, tempo and key (Media / Text tab).
