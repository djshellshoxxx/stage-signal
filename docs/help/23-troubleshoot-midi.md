# Troubleshooting: MIDI
- Controller not listed: reconnect and press Reconnect MIDI on the Setup tab.
- Mapping shows DEVICE UNAVAILABLE: the port was lost; reconnect, then Reconnect MIDI.
- Learn captures nothing: select the input port first; another program may hold the port.
- Feedback alarm: unplug the loop or disable MIDI feedback, then re-enable it explicitly.
