# Benchmark interpretation
The benchmark runs a fixed scene on mock sinks: it never transmits, broadcasts or records. A scaled run is marked non-qualifying.
Read the result as headroom: frames per second against the target, missed deadlines, drops, CPU and memory. Counters that Windows cannot supply are shown as unavailable, never as zero.
The tier decides which features are admitted (for example camera plus encoding). If you are already running and the machine is overloaded, StageSignal sheds visual work step by step; with quality locked it shows a warning instead.
