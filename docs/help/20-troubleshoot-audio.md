# Troubleshooting: audio devices
- No device listed: check the USB cable and Windows privacy settings, then Refresh list.
- DENIED: Windows blocked microphone access for desktop apps.
- DISCONNECTED: the interface was removed. Reconnect it and press Reopen same device.
- Meter flat: check the route (stereo, left or right) and the input gain on the hardware.
- Older Windows without WASAPI uses the WinMM backend automatically; device names can differ.
