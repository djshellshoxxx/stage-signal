# Troubleshooting: lighting
- Nothing reaches the fixtures: the page must read ARMED. Check the interface, host address and universe.
- CONFLICT in the patch table: two fixtures overlap addresses in one universe.
- Art-Net broadcast is refused unless the opt-in box is ticked.
- USB DMX adapters: no adapter is listed as hardware-qualified; use Art-Net or sACN where possible.
- After any fault the output stays disarmed until you press Arm.
