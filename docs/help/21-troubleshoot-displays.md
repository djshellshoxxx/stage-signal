# Troubleshooting: displays and projectors
- Projector not listed: set the Windows display mode to Extend and press Refresh displays.
- Window on the wrong screen: Identify displays, then Assign again.
- Route says Needs reassign: identical monitors; assign again to confirm.
- Black bars: the picture keeps its aspect ratio (4:3 content on a 16:9 display shows bars).
- Controls window must stay on your own screen; StageSignal never moves an audience window onto it.
