# Scene modes
- Auto: weighted automatic scene changes at beat boundaries, with minimum dwell and no recent repeats.
- Programmed: the cue list runs in order with its own durations and transitions.
- Hybrid: programmed cues plus manual changes.
Choosing a scene by hand pauses scheduled changes (override). Resume continues the current cue or moves to the next cue, as you choose, with no surprise jump.
The target selector above the pads decides which output a scene change applies to; the current target is always shown.
