# First-show walkthrough
StageSignal starts in IDLE. DMX, recording and broadcast are always off when the program starts, and it never needs a network or a login.

## Before the audience arrives
1. Setup tab, step 1: press Identify displays. A numbered label appears on every display for a few seconds. Assign the Audience output to the projector display and keep the Controls display for yourself.
2. Step 2: choose the audio input and press Open. Set the gain on your mixer or interface (hardware) until peaks stay below -6 dBFS, then tick the gain box.
3. Step 3 (optional): open the camera preview. Preview is not publication: the camera is not in any scene until you publish it.
4. Steps 4-6: MIDI ports, lighting interface and recording folder (all optional).
5. Step 7: run the benchmark once so StageSignal knows what this machine can do.
6. Press Save setup. Open or create your show (File menu) and press Ctrl+S.

## During the show
- Live tab: scene pads 1-8 (keys 1-8), banks, mode selector (Auto, Programmed, Hybrid), tap tempo.
- F5 next scene, F6 pause automation, F7 resume, F8 emergency blackout (latched), Shift+F8 restore.
- Text: write a draft, Preview, then Publish. Nothing reaches the audience until Publish.
- Recording and broadcasting use explicit Start and Stop buttons on the Record / Broadcast tab.

## After the show
Stop recording, disarm lighting, save the show. Closing the program stops everything in a safe order.
