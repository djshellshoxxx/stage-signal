# Troubleshooting: broadcast and network
- Start refused: apply settings first; the message names the invalid field.
- Certificate error: RTMPS refuses unverifiable servers; check the host name and the PC clock.
- Reconnecting: the countdown shows the next attempt; Stop cancels it.
- SRT is unavailable in this build. Use RTMPS or RTMP.
- The program needs no network for anything except a broadcast you start.
