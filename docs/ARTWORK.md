# StageSignal — software artwork

**Classification:** Software artwork for live performance.

StageSignal is an interactive audiovisual work in development for DJs, bands, and small venues. Its planned workflow combines live visuals, video and text layers, MIDI and lighting control, set recording, and optional broadcasting.

The repository contains both a written specification and a working application/core implementation. Development status, measured checks, acceptance targets, and unverified platform or hardware behaviour remain documented in the [README](../README.md), [known limitations](KNOWN_LIMITATIONS.md), and the linked specifications. The artwork label does not claim that every planned feature has passed its acceptance checks.
